# ChargeEase ML dataset

The project can run immediately using a generated academic dataset for charging-duration prediction.

For a real project demonstration, replace `charging_history.csv` with historical records using these columns:

- power_kw
- battery_capacity_kwh
- current_battery_percent
- target_battery_percent
- connector_code
- estimated_energy_kwh
- duration_minutes

This keeps the ML module free and avoids paid AI APIs.
